# 术语表

> **TL;DR**: 核心术语：目录联接（Junction）、双阶段迁移（Two-Phase Migration）、事务日志（Transaction Journal）。⚠️ 注意：目录联接 (Junction) ≠ 符号链接 (Symbolic Link)，两者在跨盘和文件/文件夹层级的支持上存在技术差异。

## D

### 目录联接 (Directory Junction)
Windows 操作系统中 NTFS 文件系统特有的重解析点（Reparse Point）类型。它专门用于将 C 盘的某个文件夹路径在文件系统层面重定向到另一个磁盘的分区中，类似于“快捷方式”但对底层应用程序完全透明。

### 双阶段迁移 (Two-Phase Migration)
本项目中为了保证数据安全采用的防丢失拷贝机制。第一阶段在目标磁盘写入 `.tmp_` 临时前缀文件夹并做大小哈希完整性校验；第二阶段完成源目录安全删除、目录联接占位以及目标目录最终激活重命名。

---

## F

### 文件占用预检 (File Lock Pre-check)
在执行物理数据移动前，利用 Windows Restart Manager 服务对目标源文件进行深度占用扫描，获取并可强制中止正在独占该文件的外部进程 PID。

---

## S

### 符号链接 (Symbolic Link)
与目录联接（Junction）类似的文件系统重定向机制，但符号链接支持文件层面的重定向，且允许使用相对路径。缺点是要求调用进程必须拥有系统级最高管理员或开发者模式权限，且在旧版 Windows 兼容性较弱。本项目的 MVP 阶段（V1.0）不使用符号链接，而使用更稳健的目录联接。

---

## T

### 事务日志 (Transaction Journal)
本地记录未决迁移任务的日志文件 `pending_jobs.json`。在迁移操作执行前写盘，操作成功建立联接后销毁，用于崩溃后自检与一键回滚。

## 缩写表

| 缩写 | 全称 | 说明 |
|------|------|------|
| **Junction** | Directory Junction | 目录联接点。NTFS 文件系统支持的跨分区目录重定向重解析点。 |
| **RM** | Restart Manager | Windows 重启管理器。用于检测和优雅解除文件占用进程。 |
| **UAC** | User Account Control | 用户账户控制。Windows 系统的管理员提权保护机制。 |
