# 日志国际化 + 自动升级 + 帮助功能 实施方案

## Context（背景）

当前 CDiskLinker v1.2.1 存在三项待补齐能力：

1. **运行日志未国际化**：后端 `engine.rs` / `commands.rs` 向前端发送的迁移进度 `detail` 和 `Err` 错误字符串均为硬编码中文（约 50 处），在前端 LogConsole 和进度条中直接透传显示，切换到 en-US 后仍是中文。
2. **缺少自动升级**：参考 `D:\project\my\Tie` 项目，需集成 Tauri 官方 `tauri-plugin-updater` + `tauri-plugin-process`，实现启动静默检查 + 手动检查 + 下载安装进度。
3. **缺少帮助功能**：用户要求首次打开弹出帮助框（含用法举例，中英文），并提供常驻入口供后续查阅。

预期结果：日志随语言切换中英文；应用可自动检查并安装新版本；首次启动有引导，用户可随时点击"?"复查用法。

## Task 1：运行日志国际化（范围 ①+②）

### 设计思路

扩展现有 `addLog(level, message, i18nKey?, params?)` 机制（[app.ts:380](file:///d:/project/my/CDiskLinker/src/stores/app.ts#L380)），让后端发送 i18n key 而非中文原文，前端翻译。

- **进度 detail（①）**：扩展 `MigrationProgress` 结构体，新增 `detail_key` + `detail_params` 字段。后端 emit 时同时携带中文 fallback（`detail`，留作 dev 调试与 message 回退）和 i18n key。前端 `migration-progress` 监听器优先用 key 翻译。
- **Err 错误字符串（②）**：后端 `Err(String)` 返回 i18n key 字符串（如 `"err.noSourceSelected"`）。前端新增 `translateError(e)` 工具函数，识别 `err.*` / `log.*` 前缀则翻译，否则按原文返回（兼容底层 OS 错误）。
- **eprintln 调试日志（③）**：保持原样，仅开发者可见，不纳入本次范围。

新增 `translateError` 工具（app.ts 顶部）：

```ts
function translateError(e: unknown): string {
  const msg = String(e)
  if (/^(err|log)\./.test(msg)) return t(msg)
  return msg
}
```

所有 `catch (e)` 中调用 `addLog('error', ..., { error: translateError(e) })`，将翻译后的文本作为 `{error}` 插值。

## Task 2：自动升级功能

### 前置条件（用户手动操作，无法代劳）

1. **生成签名密钥对**：在项目根目录执行
   ```
   npx @tauri-apps/cli signer generate -w .tauri/cdisklinker.key
   ```
   会提示设置密码，生成私钥文件和公钥字符串。
2. **配置 GitHub Secrets**（仓库 `Tonys-L/CDiskLinker` → Settings → Secrets and variables → Actions）：
   - `TAURI_SIGNING_PRIVATE_KEY`：私钥内容（`cat .tauri/cdisklinker.key` 的输出）
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`：上一步设置的密码

## Task 3：帮助功能（首次弹窗 + "?" 按钮）

### 设计思路

- 首次启动检测：`localStorage` 标记 `help-shown-v1`。App 挂载时若不存在则弹出帮助框并写入标记。用版本化 key 便于后续发新帮助时再次弹出。
- 常驻入口：右上角语言切换按钮旁加"?"按钮，点击随时打开帮助。
- 帮助内容：中英文双语，含软件作用、基本用法步骤、举例、注意事项。页脚放"检查更新"按钮（承接 Task 2 手动入口）。

#### 3.2 状态与触发（[App.vue](file:///d:/project/my/CDiskLinker/src/App.vue)）

App.vue 改为带 `<script setup>`，引入 HelpDialog + UpdateDialog + useUpdateCheck：

```ts
const helpVisible = ref(false)
const HELP_KEY = 'help-shown-v1'
onMounted(() => {
  if (!localStorage.getItem(HELP_KEY)) {
    helpVisible.value = true
    localStorage.setItem(HELP_KEY, '1')
  }
  useUpdateCheck().silentCheckOnLaunch()
})
function showHelp() { helpVisible.value = true }
```

模板：

```vue
<n-config-provider ...>
  <n-message-provider>
    <router-view @show-help="showHelp" />
    <HelpDialog v-model:visible="helpVisible" />
    <UpdateDialog />
  </n-message-provider>
</n-config-provider>
```
